# Pipeline execution order

Run commands from the repository root. Prepare the public datasets, reference
resources and model weights described in the top-level README and
[`INPUTS_AND_OUTPUTS.md`](INPUTS_AND_OUTPUTS.md).

```bash
export CONDA_SH=/path/to/miniconda3/etc/profile.d/conda.sh
export PARTITION_GPU=gpu
export PARTITION_CPU=cpu
export GPU_GRES=gpu:1
mkdir -p log
```

Execute the stages below in order. Launchers that submit SLURM jobs return
before computation finishes; wait for each stage's jobs before running a
dependent stage. Intermediate files are generated by the preceding stages.
Figure numbers refer to the manuscript.

## 1. Preprocessing and fitting

Prepare raw datasets, reference files, model weights and SLURM settings as
listed in the top-level README.

```bash
bash pipeline/00_preprocess/00a_embedding_extract.sh alphagenome borzoi enformer
bash pipeline/00_preprocess/00c_singlecell_preprocess.sh
bash pipeline/00_preprocess/00b_build_training_data.sh
bash pipeline/00_preprocess/00d_baseline_data.sh

bash pipeline/01_training/01a_transfer.sh
bash pipeline/01_training/01b_simplecnn_baseline.sh
bash pipeline/01_training/01c_alphagenome_folds.sh
bash pipeline/01_training/01d_lora.sh
bash pipeline/01_training/01e_full_finetuning.sh
```

Wait for embedding/preprocessing jobs before training-table assembly, and
for training jobs before the expression-evaluation stage.

## 2. Expression evaluation

```bash
bash pipeline/fig2_expression/21_compare_models.sh
bash pipeline/fig2_expression/22_multifold_baseline.sh
bash pipeline/fig2_expression/23_compare_training.sh
bash pipeline/fig2_expression/24_clustering_signature.sh
OUTDIR=results/expression_evaluation \
  bash pipeline/additional_analysis/70_expression_summary_array.sh
```

Outputs include correlation tables, AnnData objects and individual expression
panels under `figures/`, `across_study/` and `adata/`. Step 70 computes expression
correlations, expression-quintile evaluations and bootstrap intervals from the
fitted outputs of all backbones and AlphaGenome fold models.

Launcher 24 runs the embedding, cluster-concordance and observed-separation
scripts in order. The third script supplies Fig. S3b: it quantifies
perturbation separation in the observed pseudobulk matrices against a
gene-permutation null and writes
`across_study/perturbation_separation/gap_ratio_barplot.svg` with the
accompanying tables. It reads `figures/{study_full}/embedding/clustering_metrics.txt`
from the second script, so run the three in sequence rather than individually.
Defaults reproduce the reported values (2,000 top-variance genes, 20 permutation
repeats, seed 0); the environment variables listed at the top of
`scripts/expression_model_performance/23_perturbation_separation.py` override them.

Wait for all 56 array tasks: 12 studies × four backbones, plus four AlphaGenome
folds for Norman and CD8T. Each `results/expression_evaluation/run_XX/output/`
contains `gene_correlations.tsv`, `condition_correlations.tsv`,
`expression_quintile_summary.tsv` and `backbone_comparison_summary.tsv`.
These quantify expression agreement and bootstrap uncertainty for Fig. 3 and S5.
Use a new `OUTDIR` for each run.

## 4. In-silico mutation

First generate the union-gene lists from the training input tables. This
creates `union_genes_{martin,norman}.txt` and `pert_list_{martin,norman}.txt`
under `attribution_analysis/captum_union/`. For the Martin locus plots in
Fig. 4a–c, submit one union-attribution job for each of the 13 Martin
conditions listed in `pert_list_martin.txt`:

```bash
source pipeline/_common.sh
pipeline_activate_conda singlecell
python scripts/attribution_evaluation/51a_create_union_gene_list.py

union_dataset=MartinRufino2025_mixscape_exnp_train
union_suffix=$(default_study_suffix alphagenome)
union_genes=attribution_analysis/captum_union/union_genes_martin.txt
while IFS= read -r union_pert; do
  sbatch --partition="${PARTITION_GPU}" --gres="${GPU_GRES}" \
    --mem="${MEM_GPU}" --time=24:00:00 --ntasks=1 --cpus-per-task=4 \
    --job-name="union_${union_pert}" \
    --output="log/union_${union_pert}_%j.out" \
    --error="log/union_${union_pert}_%j.err" \
    pipeline/01_slurm.sh -p captum_union \
    "$union_dataset" "$union_suffix" alphagenome condition \
    "$union_pert" "$union_genes" _union
done < attribution_analysis/captum_union/pert_list_martin.txt
```

Wait for all union-attribution jobs to finish before the locus plotting in
step 43 (`Martin_full`). Each job writes
`attribution/{study_full}/{pert}/{pert}_union_raw_attribution.h5`.
The gene lists must exist before these jobs are submitted. Step 40 then
extracts TF-MoDISco seqlet metadata and motif-core intervals; it also
regenerates the same gene lists. Seqlet extraction and mutation-target
attribution scores use the 128-bp window files
`attribution/{study_full}/{pert}/{pert}.h5` from section 3, while the locus
plotting reads the union raw H5 files.

Then run the full and matched mutation chains:

```bash
bash pipeline/fig3_attribution/40_prepare_seqlet_metadata.sh 0.05

bash pipeline/fig3_attribution/41_prepare_mutation_targets.sh Martin_full
bash pipeline/fig3_attribution/42_run_mutation_array.sh Martin_full
# wait for every mutation job
bash pipeline/fig3_attribution/43_post_mutation_figures.sh Martin_full

bash pipeline/fig3_attribution/41_prepare_mutation_targets.sh Martin_matched
bash pipeline/fig3_attribution/42_run_mutation_array.sh Martin_matched
# wait for every mutation job
bash pipeline/fig3_attribution/43_post_mutation_figures.sh Martin_matched

bash pipeline/fig3_attribution/41_prepare_mutation_targets.sh Norman_matched
bash pipeline/fig3_attribution/42_run_mutation_array.sh Norman_matched
# wait for every mutation job
bash pipeline/fig3_attribution/43_post_mutation_figures.sh Norman_matched

OUTROOT=results/mutation_effects \
  bash pipeline/additional_analysis/72_mutation_aggregation.sh Martin_matched
OUTROOT=results/mutation_effects \
  bash pipeline/additional_analysis/72_mutation_aggregation.sh Norman_matched
```

For each study, `results/mutation_effects/P2_{Martin,Norman}_matched/output_v2/`
contains `mutation_pairs.tsv`, `mutation_gene_effects.tsv`,
`mutation_perturbation_effects.tsv`, `mutation_summary.tsv`,
`mutation_tertile_perturbation_effects.tsv` and `mutation_tertile_summary.tsv`.
The analysis averages five mutation seeds and aggregates paired motif–control
effects by gene and perturbation, with perturbation-bootstrap intervals for
Fig. 4f and S9b. Use the fixed tertile boundaries in launcher 72 and a new
`OUTROOT` for each run.

Draw the high-attribution tertile panels of Fig. 4f and Fig. S9b from those
tables, passing the same results root used for 72:

```bash
RESULTS=results/mutation_effects \
FIGURES=figures/mutation_effects \
  bash pipeline/additional_analysis/75_tertile_panels.sh
```

This writes `results/mutation_effects/tertile_panels/{Martin,Norman}_tertile/`
with the panel source-data tables, `run.json` and the panel SVG for each study,
using bootstrap seed 42 and 10,000 perturbation resamples.

`pipeline/additional_analysis/78_print_size_panels.sh` draws Fig. 4d, Fig. 4f,
Fig. S8a/b and Fig. S9b at their final printed size, and is the plotting code
for the Fig. 4d and Fig. S8a/b panels. It reads the step-71 AUPRC root and this
`tertile_panels/` directory, so run 71 and 75 first. Its defaults assume both
sit under one results root; with the split roots used above, call the figure
script with the two paths directly:

```bash
conda activate singlecell
python scripts/additional_analysis/fig4_figS8_figS9_print_panels.py \
  --auprc-root results/enhancer_benchmark \
  --martin-tertile results/mutation_effects/tertile_panels/Martin_tertile \
  --norman-tertile results/mutation_effects/tertile_panels/Norman_tertile \
  --out results/print_panels \
  --figure-out figures/print_panels
```

This step only changes panel geometry; it recomputes no reported value.

## 5. Lineage and compound analyses

For Norman, run the resume-safe all-condition attribution route and TF-MoDISco
aggregation:

```bash
bash pipeline/fig4_lineage/10_captum_array.sh \
  NormanWeissman2019_filtered_mixscape_exnp_train alphagenome
# wait for Captum completion markers
bash pipeline/fig4_lineage/22_tfmodisco_array.sh \
  NormanWeissman2019_filtered_mixscape_exnp_train alphagenome
# wait for TF-MoDISco completion markers
bash pipeline/fig4_lineage/23_tfmodisco_aggregate.sh \
  NormanWeissman2019_filtered_mixscape_exnp_train

bash pipeline/fig4_lineage/30_signature_axis.sh
OUTDIR=results/norman_partitions \
FIGDIR=figures/norman_partitions \
  bash pipeline/additional_analysis/73_norman_partitions.sh
bash pipeline/fig4_lineage/31_seqlet_mutation_array.sh
# wait for all nine marker-gene jobs
bash pipeline/fig4_lineage/32_seqlet_cancellation.sh
```

Step 30 tests the positive and negative motif patterns separately, retains the
direction with the larger absolute correlation, applies a within-motif
selection adjustment (`min(1, k p)`, where `k` is the number of eligible
directions), and then applies Benjamini–Hochberg correction across unique
motifs. The per-motif inputs to this decision are written to
`C_motif_direction_tests_erythroid.tsv` and
`C_motif_direction_tests_granulocyte.tsv`.

Step 73 recomputes observed and fitted partitions using the same held-out loci.
Outputs under `results/norman_partitions/` include `adata_real.h5ad`,
`adata_pred.h5ad`, `real_membership.tsv`, `pred_membership.tsv` and
`partition_metrics.json` (ARI and NMI). Individual Fig. 5a panels are written
under `figures/norman_partitions/`. Use a new `OUTDIR` for each run.
