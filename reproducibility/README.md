# Running the manuscript analyses

Prepare the public datasets, reference resources and model weights, then run
pipeline stages from the repository root in the order listed below.

1. [`../environments/README.md`](../environments/README.md): Conda setup.
2. [`INPUTS_AND_OUTPUTS.md`](INPUTS_AND_OUTPUTS.md): external inputs, generated
   intermediate files and fixed parameters.
3. [`RUN_ORDER.md`](RUN_ORDER.md): preprocessing, fitting, expression evaluation,
   attribution, enhancer/motif, mutation, lineage and compound-analysis launchers.

## Study and model identifiers

```text
MODEL = alphagenome
MODEL_SUFFIX = alphagenome_transfer_epoch100_batch256_adamw5e3

MARTIN = MartinRufino2025_mixscape_exnp_train

```

Study/model labels are defined in `dataset_model_config.py`. The model suffix
is generated by `pipeline/_common.sh`.
