# Pipeline inputs and outputs

Prepare external inputs at the relative paths below. Intermediate files are
generated by the pipeline stages in `RUN_ORDER.md`.
Study/model identifiers are defined in [`README.md`](README.md).

## External resources

Prepare raw single-cell inputs under `data/adata/` and MartinRufino count
matrices and metadata under `data/MartinRufino/`. Prepare these reference files:

```text
fasta/GRCh38.p14.genome.fa
fasta/gencode.v46.chr_patch_hapl_scaff.basic.annotation.gff3
fasta/gencode.v46.chr_patch_hapl_scaff.basic.annotation.gtf
reference/jaspar/clusters.tab
reference/gimmemotifs/motif_db/JASPAR2022_vertebrates.pfm
```

Pretrained model weights are required for sequence embedding and attribution
stages. Data acquisition commands are listed in
`genperturb/preprocess/01_download_data.sh`.

## Configuration

| File | Purpose |
|---|---|
| `dataset_model_config.py` | Active studies/models, fixed model suffixes, labels, and colors used by expression evaluation |
| `pipeline/_common.sh` | Default study list, model suffix, Conda activation, SLURM resources, and cluster overrides |
| `environments/*.yml` | Installable package specifications distributed with this repository |
| `environments/README.md` | Environment creation and post-install commands |

Use matching checkpoints, prediction arrays, expression TSVs and training BEDs.
Prediction row/column order follows the matching training input.
Intermediate files are outputs passed from one stage to the next. Generate
them with the preceding commands in `RUN_ORDER.md`, or reuse matching files
at the paths listed below. For example, expression evaluation reads fitted
prediction arrays, mutation-target preparation reads seqlet tables and
attribution H5 files, and mutation summaries read the mutation predictions.

### Fig. 4d and Fig. S8 enhancer benchmark

Prepare the MartinRufino supplementary workbooks under
`data/science.ads7951_tables_s1_to_s6/` and the ABC/rE2G annotations used
by the enhancer stage. The pipeline derives ATAC BEDs, annotation BEDs and
scored candidates at the paths below.

```text
data/science.ads7951_tables_s1_to_s6/science.ads7951_table_s2.xlsx
data/science.ads7951_tables_s1_to_s6/science.ads7951_table_s3.xlsx
reference/martin_atac/{TF}.bed
cre_gtgenes/{MARTIN_FULL}/{pert}/abc_score_{pert}.bed
cre_gtgenes/{MARTIN_FULL}/{pert}/re2g_{pert}.bed
cre_gtgenes/{MARTIN_FULL}/{pert}/re2g_extended_{pert}.bed
attribution/{MARTIN_FULL}/{pert}/{pert}_gtgenes_raw_attribution.h5
cre_gtgenes/{MARTIN_FULL}/unified_peaks/unified_peaks_{pert}.bed
cre_gtgenes/{MARTIN_FULL}/scored_peaks/scored_peaks_{pert}.tsv
```

Use `scripts/additional_analysis/auprc_manifest.tsv` for the 12-perturbation input list.
Its columns are `perturbation, cre_dir, raw_h5, atac_bed, original_union`;
paths are relative to the manifest directory. Each `cre_dir` contains the
three annotation BEDs above, with empty files for annotations without candidates.

| Parameter | Value |
|---|---|
| Context length | 1,048,576 bp |
| Minimum absolute log2FC | 0.5 |
| Minimum positives per distance stratum | 10 |
| Unavailable attribution scores | `zero` |
| GenPerturb score | Mean of the top 10% of per-base absolute four-channel differential Input × Gradient values in the raw H5 |

Candidate intervals are defined by enhancer annotations and TSS windows.
The scoring stage generates the unified BEDs and scored TSVs listed above.

## Additional quantitative analyses

Commands and output overrides for steps 70–75 and 78 are in `RUN_ORDER.md`.
They use the prediction, training TSV/BED, attribution and mutation files
generated by preceding pipeline stages. Every step refuses an existing output
directory, so pass a new root for each run.

| Step | Output directory in the runbook | Main outputs |
|---|---|---|
| 70 | `results/expression_evaluation/run_XX/output/` | `gene_correlations.tsv`, `condition_correlations.tsv`, `expression_quintile_summary.tsv`, `backbone_comparison_summary.tsv` |
| 71 | `results/enhancer_benchmark/` | `output/auprc_per_perturbation.tsv`, `A3/paired_auprc_summary.tsv` |
| 72 | `results/mutation_effects/P2_{Martin,Norman}_matched/output_v2/` | `mutation_pairs.tsv`, `mutation_perturbation_effects.tsv`, `mutation_summary.tsv`, `mutation_tertile_summary.tsv` |
| 73 | `results/norman_partitions/` | `adata_real.h5ad`, `adata_pred.h5ad`, `real_membership.tsv`, `pred_membership.tsv`, `partition_metrics.json` |
| 74 | `results/nr3c1_{condition,compound}_test/` | `nr3c1_tie_aware_tests.tsv`, `compound_group_audit.tsv` |
| 75 | `results/mutation_effects/tertile_panels/{Martin,Norman}_tertile/` | `A5_{study}_tertile_effects.tsv`, `A5_{study}_tertile_effects_summary.tsv`, Fig. 4f and Fig. S9b panel SVG, `run.json` |
| 78 | `results/print_panels/` | Fig. 4d, Fig. 4f, Fig. S8a/b and Fig. S9b redrawn at final printed size |

Step 75 consumes `mutation_pairs.tsv` from step 72 and writes the
`A5_*_tertile_effects*.tsv` tables that step 78 reads, so run 72 → 75 → 78.
Step 75 also computes the perturbation-bootstrap intervals and sign tests
quoted in the Fig. 4f and Fig. S9b legends, using bootstrap seed 42 and 10,000
resamples of perturbations. Step 78 is the plotting code for the Fig. 4d and
Fig. S8a/b panels; it recomputes no reported value.
